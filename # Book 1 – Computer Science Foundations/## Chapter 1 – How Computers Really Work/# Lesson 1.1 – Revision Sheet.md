# Definition of a Computer

A computer is a programmable electronic machine that:

- Accepts input
- Processes data
- Stores information
- Produces output

Every software application follows this model.

---

# Four Fundamental Operations

```text
Input

↓

Processing

↓

Storage

↓

Output
```

### Input

Information entering the system.

Examples

- Keyboard
- Mouse
- HTTP Request
- JSON Payload
- File Upload

---

### Processing

Operations performed by the CPU.

Examples

- Validation
- Calculation
- Searching
- Sorting
- Encryption
- Business Logic

---

### Storage

Stores information.

Two categories

Temporary

- CPU Registers
- Cache
- RAM

Permanent

- SSD
- HDD
- Database

---

### Output

Final result produced by the system.

Examples

- JSON Response
- HTML
- PDF
- Email
- SMS

---

# Why Computers Were Invented

Computers solve problems that are:

- Too repetitive
- Too fast
- Too complex
- Too large
- Too error-prone for humans

Computers execute instructions consistently and quickly.

---

# Important Principle

A computer **does not think**.

It only executes instructions.

The intelligence comes from the programmer and the algorithm.

---

# Major Components of a Computer

| Component | Responsibility |
|-----------|----------------|
| CPU | Executes instructions |
| RAM | Stores running programs and active data |
| Storage | Stores permanent data |
| Input Devices | Receive information |
| Output Devices | Display results |

# Senior Engineer Notes

When analyzing backend performance, experienced engineers think beyond code.

Typical questions include:

- Is CPU utilization high?
- Is memory exhausted?
- Is the JVM spending time in Garbage Collection?
- Is the database slow?
- Is the network introducing latency?
- Is disk I/O the bottleneck?

Strong engineers optimize the entire system, not just Java code.

# Key Takeaways

✅ Java programs are compiled into bytecode.
